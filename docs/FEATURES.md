# Реестр функций 1.3

«Реализовано» означает, что есть код и доступный интерфейс. Это не заменяет проверку на физических устройствах или внешний аудит. Серверные возможности требуют обновления relay из этой ветки.

## Первые десять направлений

| Функция | Фактический результат |
| --- | --- |
| APNs и фоновые звонки | Клиент и provider готовы; нужны ключи Apple и физическая проверка |
| Double Ratchet и аудит | Не реализованы; отдельный план в PROTOCOL-V2.md |
| Сетевая приватность | SOCKS5, внешний Tor, запрет failover; APNs и Safari вне этого маршрута |
| Запросы от незнакомцев | Реализованы, медиа и receipts до принятия скрыты |
| Взаимная проверка ключей | QR с обоими полными ID и проверка совпадения |
| Надёжная доставка и файлы | Задержки повтора, ошибки, дедупликация, Range для ciphertext, отмена загрузки |
| Перенос личности | Зашифрованный парольный файл; QR-переноса и синхронизации устройств нет |
| Управление памятью | Размеры по чатам, очистка медиа и ciphertext-кэша, серверные квоты |
| Папки и поиск | Папки, поиск, фильтры, пагинация и переход к сообщению |
| Проверки качества | Серверные тесты, Debug/Release/XCTest CI; ручные сценарии на телефоне остаются |
