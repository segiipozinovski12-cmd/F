# VO1D Messenger

Нативный мессенджер для **iPhone и iPad, SwiftUI, iOS 17+**. Проект Xcode уже включён: генераторы, CocoaPods и сторонние Swift-пакеты не нужны.

## Запуск в Xcode

```bash
git clone --branch codex/vo1d-messenger https://github.com/segiipozinovski12-cmd/F.git VO1D-Messenger
open VO1D-Messenger/ios/VO1DMessenger.xcodeproj
```

Выбери схему **VO1DMessenger**, симулятор iPhone и нажми **Run**. Для физического iPhone выбери свою **Team** в Signing & Capabilities и уникальный Bundle Identifier. Сертификаты и Apple-аккаунт в репозитории отсутствуют.

На первом экране можно создать профиль без сервера и сразу открыть интерфейс. Для настоящей переписки подключи сервер в профиле. Нет выдуманных собеседников, автоматических ответов или фиктивного статуса доставки.

## Возможности

- Криптографическая личность без номера, почты, пароля и адресной книги.
- Личные чаты и закрытые группы до 16 участников с фиксированным составом.
- Добавление по ID, ссылке или QR; показ QR; локальное имя и ручная отметка проверки отпечатка.
- Текст, фото с удалением EXIF, файлы до 3 МБ, голосовые до 3 минут.
- Ответы, реакции, редактирование и удаление своих сообщений у получателей.
- Статусы «в очереди / отправлено серверу / доставлено / прочитано»; для групп статус отмечает хотя бы одного получателя.
- Сохранённая очередь, повторная отправка, серверная дедупликация и подтверждение получения.
- Поиск по чатам и текстам, закрепление, архив, черновики.
- Исчезновение собственных новых сообщений через 1 час, 24 часа или 7 дней с момента отправки.
- Блокировка контактов на устройстве и сервере, отключение прочтений.
- Face ID / системный код устройства, скрытие экрана при сворачивании.
- Шифрованная локальная история; ключи в Keychain, доступ только после разблокировки устройства.
- Удаление аккаунта, его очередей и локальных ключей.
- Собственный сервер Python/SQLite, Docker Compose + Caddy HTTPS, тесты, GitHub Actions.

## Сервер на твоём Mac — два симулятора

```bash
cd VO1D-Messenger
python3 -m venv .venv
source .venv/bin/activate
pip install -r server/requirements.txt
python3 server/app.py
```

В обоих симуляторах введи `http://127.0.0.1:8080`, создай разные личности и обменяйся приглашениями из **Профиль → Моя личность**. На физическом iPhone localhost означает сам телефон: используй сервер с HTTPS. Незащищённый HTTP допускается кодом только для loopback в Debug; Release требует HTTPS.

## Сервер в интернете

Нужен собственный сервер с Docker и доменом, у которого A/AAAA указывает на этот сервер. Порты 80 и 443 должны быть открыты.

```bash
cp .env.example .env
# В .env замени chat.example.com своим доменом
 docker compose up -d --build
```

В iOS укажи `https://твой-домен`. Caddy получает TLS-сертификат автоматически. Данные сохраняются в Docker volume `relay-data`. Инструкция: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

## Что означает приватность

Содержимое шифруется отдельно для каждого получателя: X25519 → HKDF-SHA256 → AES-256-GCM, подписи Ed25519, публичные ключи связаны подписанным идентификатором. Приватные ключи не отправляются на сервер. Протокол использует Apple CryptoKit.

Это **псевдонимная переписка со сквозным шифрованием**, а не гарантия сетевой анонимности. Сервер/хостинг видит IP, ID сторон, время и размер трафика. Собственный протокол не проходил внешний аудит, не реализует Double Ratchet и не обещает forward secrecy при компрометации долгосрочного ключа получателя. См. [docs/SECURITY.md](docs/SECURITY.md).

В этой версии **нет звонков, APNs/push, фоновой доставки при закрытом приложении, федерации серверов, нескольких устройств и восстановления ключей**. Удаление и таймеры не стирают скриншоты и копии у собеседников. Не следует использовать неаудированный клиент для ситуаций с высокой ценой компрометации.

## Проверки

```bash
python3 -m unittest discover -s server/tests -v
xcodebuild test -project ios/VO1DMessenger.xcodeproj -scheme VO1DMessenger \
  -destination 'platform=iOS Simulator,name=iPhone 16' CODE_SIGNING_ALLOWED=NO
```

Выбери имя установленного симулятора (`xcrun simctl list devices available`). Workflow автоматически выбирает доступный iPhone, запускает XCTest и проверяет Release-сборку для устройства. `.ipa` с подписью создаётся на твоём Mac через Archive, с твоей Team.

## Структура

| Путь | Назначение |
| --- | --- |
| `ios/VO1DMessenger.xcodeproj` | Готовый проект и общая схема Xcode |
| `ios/VO1DMessenger/` | SwiftUI, CryptoKit, Keychain, клиент, шифрованное хранилище |
| `ios/VO1DMessengerTests/` | Криптографические и транспортные тесты |
| `server/` | Relay, Dockerfile, TLS-конфигурация |
| `server/tests/` | Интеграционные проверки безопасности и доставки |
| `docs/` | Протокол, ограничения, развёртывание |
| `scripts/generate_project.py` | Воспроизводимое обновление проекта после добавления Swift-файлов |
